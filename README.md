# 简历生成器

一个无需安装依赖的本地简历生成器，直接用浏览器打开 `index.html` 即可使用。

## 功能

- 编辑基本信息、个人图片、基础技能、教育经历、工作经历、项目经历、成果 / 获奖。
- 支持多种简历风格：经典商务、现代蓝、紧凑黑白、Awesome 学术、Flow 清晰、Novo 现代、Canva 极简、中文表格。
- 支持调色盘自定义简历强调色、侧栏色、区块色和正文色。
- 右侧 A4 简历预览可直接编辑，适合导出前做细节调整。
- 支持导出 PDF/打印、HTML、Markdown、JSON 数据。
- 自动保存到浏览器本地缓存，可通过 JSON 导入恢复或迁移数据。

## 使用

1. 双击打开 `index.html`。
2. 在左侧表单维护内容，右侧会实时生成简历。
3. 选择风格和输出格式后点击“导出”。
4. 选择 PDF 时会打开浏览器打印窗口，可在目标打印机中选择“另存为 PDF”。

## 文件说明

- `index.html`：页面结构和编辑表单。
- `styles.css`：编辑器、A4 预览和多套简历风格。
- `app.js`：数据模型、实时预览、图片导入、JSON 导入和多格式导出。
